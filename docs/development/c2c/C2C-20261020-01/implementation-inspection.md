## Source mapping and checks

- `Array.h`: owning contiguous vector; checked access, explicit empty data, source-empty moves/self-move handling, copy-and-swap assignment and storage-following swap. No external storage or persistent state.
- `Domain.h`, `Grid.h`: endpoints/spans/cardinalities/spacing validation before divisions or allocation; copied domain and exact physical endpoints; checked interior coordinates. Domain validation helper is private.
- `Types.h`, `Equation.h`, `CrankNicholson1D.h`, `PDE.h`: prescribed names/defaults, all public units exported, retained grid/PDE references, deleted scheme assignments, finite theta range, no callback evaluation at construction. Both solve entry points validate before solve scratch/callbacks; original uniform API remains direct.
- `Checked.h`: each binary64 arithmetic primitive stores a separate volatile double before checking finiteness. Every scheduled geometric/coefficient/row/transfer/indicator operation calls one primitive in statement order. This prevents multiply-add contraction from bypassing the intermediate check under the documented binary64 model. Finite underflow is retained. No wider arithmetic, rescaling/retry, clipping, pivoting, regularization or fallback is implemented.
- `Tridiagonal.h`: alias/shape/input validation precedes scratch allocation; original-row scales and strict relative pivot threshold (including equality failure), pivot gate immediately upon formation, private p/y/x scratch and commit by swap only after full successful substitution. Per-operation divisions/products/subtractions are separately checked. Coefficients are read-only and may alias one another.
- `CrankNicholson1D.h` uniform `step`: prescribed endpoint averages, `r=(dt/dx)/dx`, `s=(dt/dx)/2`, `ar/bs/cdt` then q entries; separate theta/source/old-state terms and displayed sum order; source t0 omitted at theta1; left correction before right (both on nx3); exactly nt steps and literal final boundary assignment.
- Adaptive `step`: hL/hR/H positivity, prescribed v/r/z/s sequence followed by ar/bs/cdt/d/q sequence; then the shared theta-row/Thomas policy. The adaptive geometric schedule is used even on currently uniform meshes.
- `indicators`: complete left-to-right h/dU/s pass; complete jump/abs/min/half/C pass; checked endpoint copies and cell max pass. Pre-refinement completes before caps/tolerances/midpoints; pre-coarsening recomputes on resulting mesh before eligibility.
- `adapt`: contiguous x/value/leaf vectors; each leaf has original root and dynamically sized dyadic byte path, preserving sibling identity beyond fixed-width bit counts without imposing a new depth limit. One opportunity at initialization and after nonfinal steps only. Strict refine/coarsen comparisons, sticky limitation flag, preflight every requested midpoint before all-or-none overflow-free capacity decision; no sampling or transfer for blocked batches. Exact retained width/midpoint feed physical offset/alpha/beta/pL/pR/sum transfer. Initial inserted points use IC. New children are excluded from same-opportunity merging; only disjoint old siblings merge once; old nodes/values otherwise retained. Events are recorded after successful transfer, in left-to-right refine then coarsen order. All state/events are solve-local, so failures return no partial result.
